# PRD 3.6 / 3.7 核对与调整

核对日期：2026-10-18。结论：原实现均为部分满足；本次补齐主要交互，仍有下列明确限制，不标记为全部满足。

## 3.6 Dashboard

| 设计项 | 原状 | 调整后 |
| --- | --- | --- |
| 顶部固定状态、快速操作 | 随页面滚动，无菜单 | sticky 状态栏；占用率、运行状态、事件时间跨度；固定状态栏保留导出及“总览诊断”导航；告警、规则和诊断数据统一位于总览右侧 |
| 当前模式 | 插件未接收宿主会话模式字段 | 沿用宿主会话页原有的模式展示，不根据运行状态推测标准/计划等模式 |
| 四类关键指标 | 六张非交互卡片，缺错误率/频率主值 | Token 消耗、工具调用、摘要压缩频率、工具错误率；均有趋势与点击跳转、高亮 |
| Tab 过渡 | 直接替换 | 轻量淡入；遵循 reduced-motion |
| 缩放、拖拽、悬停、图例 | 时间线支持；工具图例静态；Team 为 HTML 条形 | 时间线保留原交互；工具图和 Team 忙碌图使用缩放拖拽视口，支持图例筛选、悬停与 SVG 导出 |
| 图片导出 | 统一入口，缺少当前图表标识且颜色可能丢失 | 当前图表 PNG 入口，固化计算后的 SVG 样式，白底深色文字；没有图表的列表页给出明确提示 |
| 数据区搜索/筛选/排序 | 无 | 诊断区支持文本搜索、事件/指标类型筛选、事件序号/指标标识升降序 |
| 批量复制/导出 | 无 | 批量操作作用于当前筛选结果，JSON 导出；另保留完整原始日志下载 |
| 默认展开、重复消息列表 | 与用户后续偏好冲突 | 按用户已确认要求继续默认折叠，不恢复重复消息列表 |
| 小屏单列 | 自适应多列，但未保证单列 | <=640px 四类指标自动单列；告警面板宽度不超过视口 |
| 加载反馈 | 仅空白提示 | 投影尚未到达时显示骨架与加载状态 |

### 3.6 仍需区分的边界

- 不是每一种静态图都硬套同一种交互：组成饼图继续用分区筛选和悬停，未增加无业务意义的时间轴平移。
- PNG 导出导出当前 Tab 的首个 SVG 图表；纯消息/卡片页无 SVG 时提供提示，不伪造导出成功。
- Team 新图只在成员数据可用时展示；当前真实验证会话无 Team 成员，未把该空态说成真实成员数据已验证。
- 插件不掌握宿主“标准/计划”等模式字段；宿主自己的模式栏保持为模式的事实来源。

## 3.7 告警

| 设计项 | 原状 | 调整后 |
| --- | --- | --- |
| 右侧面板 | 仅总览卡片和铃铛下拉 | 按最新用户要求聚合为总览右侧诊断中心，移除铃铛和总览正文重复告警 |
| 严重级别排序、状态/级别筛选 | 仅排序 | 未处理/已处理/已忽略/全部，全部/严重/警告/建议 |
| 时间戳 | 无 | 本浏览器首次检测时间持久保存，不冒充宿主原始故障发生时间 |
| 原因、建议、相关数据 | 文本建议 | 展开详情、当前值/阈值图示、跳转对应分析 Tab |
| 忽略和处理 | 全局 localStorage 会串会话 | 按 sessionId 隔离，状态可通过筛选查看 |
| 阈值与类别开关 | 阈值有，开关无；比例输入越界可保存 | 类别逐项开关、比例0–1校验、保存值校验、恢复默认 |
| 连续重复 >3 | 错用重复组数 | 使用 maxRunLength，严格超过3次触发 |
| 长间隔 | 默认超过2段才触发 | 默认存在1段宿主统计的30秒长间隔即提示 |
| 无告警 | 可能把已忽略误报为全部阈值正常 | 显示当前无未处理告警，保留状态筛选入口 |
| 大量告警 | 无折叠 | 按严重程度展示前5条，其余可展开；当前规则最多5类 |
| 自动应用建议 | 原先未实际应用 | 已接通基础压缩策略持久化、预览调整及直接应用；其他建议提供配置路径 |

### 自动应用建议

用户已授权支持配置写入。压缩策略通过宿主配置编辑器完成持久化、加载与回读校验；详细范围见本文末尾的更新说明。其他建议需要工具级证据，不自动生成未知参数。

## 最新布局调整

按用户后续要求，告警和诊断数据均归属总览 Tab 右侧的诊断中心，不再使用全局浮层和铃铛；其他 Tab 不渲染诊断中心。右侧包含告警筛选、规则设置和默认折叠的原始数据入口，小屏堆叠在总览内容后。


## 诊断配置应用更新

已实现配置路径查询、预览调整后应用、直接应用推荐配置。通过插件拥有的 `trajectoryConfiguration` Remote，使用宿主 `configEditor.edit` 持久化并执行正常 Loader 校验、重载与失败回滚；客户端通过 Gateway RPC 调用。支持顶层活动基础压缩插件及 Agent 预设内（含 group 数组）的基础压缩配置。停用的顶层插件不会被误选。

上下文满载推荐提前压缩，频繁压缩推荐提高触发比例。界面显示当前值、目标比例、开启自动压缩，以及修改所有模型覆盖策略的范围。多个配置目标必须先选择；预设修改仅对新建会话生效，界面明确说明。写入前比较目标原始配置以拒绝并发覆盖，写入后回读确认。错误会显示，且不会自动把告警标记为已处理。

工具错误、重复调用与延迟无法仅凭聚合指标推断可靠的参数修复或缓存策略，因此提供真实配置文件路径和手动设置导航，不生成不存在的宿主配置项。本次用户授权配置写入，取代此前基于 PRD 只读条款禁用应用的实现。
