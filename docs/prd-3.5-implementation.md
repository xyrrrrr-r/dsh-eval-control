## 数据边界

- 历史快照每侧最多 32 条消息，每条沿用 200 字符内容节选；受影响消息最多取 24 条，其余位置给保留消息。展示消息总数和截断提示。
- 生成摘要最多 4000 字符，注入预览最多 1000 字符。完整内容走日志下载，不塞入实时投影。
- 快照针对消息表面，不包含工具定义的全文；Token 卡片也沿用同一消息表面口径。
- 触发原因不根据 Token 高低猜测。轮次外独立事务或显式 sourceCommandId 可确认手动；轮内事件不等于可确认自动。
- 老的投影数据可以显示卡片并降级；加载新版宿主后通过 stateVersion=5 从持久事件日志重建快照。

## 验证

- 主机与客户端 TypeScript 检查、完整构建。
- 后端：替换配对、历史不可变、错误配对降级、快照有界、schema 与 wire 校验。
- 客户端：左右对比、红绿高亮、双向同步滚动及开关、注入增量、缺少详情降级、完整日志 URL。
- 真实 4399 会话：重建历史快照、展开卡片、打开对比视图、下载会话日志 ZIP。
