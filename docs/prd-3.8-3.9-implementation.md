# PRD 3.8 / 3.9 实现说明

## 3.8 对比分析

| 要求 | 实现 |
| --- | --- |
| 选择 2–4 个会话 | 对比 Tab 的可搜索多选列表；当前会话可取消，不强制包含；开始按钮控制读取时机，超过四个后禁选 |
| 摘要信息 | 标题、更新时间、运行状态；加载后展示会话 ID、轮次、步骤及模型 |
| 历史数据 | `sessions.using` 借用并读取 analytics、timeline 和 stats 投影，不启动 Agent；离开视图后忽略过时结果 |
| Token 柱状图 | 各会话的消耗条形对比，显示原始值；归一化模式补充相对最大值百分比 |
| 上下文折线 | 与上下文演化共用折线缩放：框选、Shift 拖拽平移、双击和按钮重置；共享图例显隐且保留横轴范围；完整窗口/适配数据纵轴切换（原始模式按最大已知窗口，归一化按 100%）；可按窗口占用和请求进度归一化 |
| 多维雷达 | Token、摘要压缩频率、工具错误率和模型耗时的相对表现；仅使用每个会话均可用的轴，至少三轴 |
| 差异高亮 | 默认高亮 `(max-min)/max` 最大的一项，点击指标切换；雷达对应轴同步高亮 |
| 差异报告 | 给出最低 Token、压缩频率、错误率及耗时，支持并列；缺失值不参与排名并显示覆盖数量 |
| 最佳实践 | 按最低值会话给出可复现的检查建议，同时说明任务、模型与质量可比的前提 |
| 数据不可用 | 会话独立错误状态、指标占位与雷达降级，不将缺失值当作零 |

口径：Token 消耗为未缓存输入加输出，未换算计费金额。折线额外包含缓存读；归一化请求进度不是相同任务阶段。雷达半径为原始值 / 所选会话本轴最大值，保留真实比例且不添加半径基线；全零轴均绘在中心。越靠近中心数值越小，图中显示刻度、轴上限、可悬停顶点和原始值表；不是能力或质量评估。对比结果是点击开始时的快照，选择发生变化后提示重新开始。团队报告使用最后一次完成的对比快照。

## 3.9 导出与分享

| 要求 | 实现 |
| --- | --- |
| 顶部导出菜单 | 格式、模板、标题、生成进度和下载状态 |
| PDF | 浏览器本地生成 A4 多页文件；中文栅格化、真实表格、重复表头、上下文图和页码；无需云端或打印对话框 |
| Markdown | 文本表格与图表样本；遵循所选报告章节 |
| JSON | 原始投影、告警和所选对比快照；明确不按模板裁剪 |
| PNG | 当前 Tab 首个 SVG 图表；保留 viewBox，解析主题色并采用白底；没有图表时可见错误与重试 |
| 离线 HTML | 无外部资源，包含图表、指标和分析；对文本转义 |
| 报告模板 | 简洁、详细、团队、自定义；自定义标题与章节保存在当前浏览器，重新打开可恢复 |
| 分享链接 | 经认证的 Gateway RPC 创建宿主本地持久化快照，公开路由仅提供隔离的只读报告 |
| 有效期 | 7 天、30 天或永久，服务端校验；过期返回 410 并显示“链接已过期” |
| 权限 | 公开链接或 8–128 字符密码；密码经随机 salt + scrypt 存储，错误密码不返回报告 |
| 分享反馈 | 尝试复制，失败时保留可手动复制的链接；可打开及撤销分享 |
| 导出失败 | 展示具体错误与重试按钮，保留所选选项 |

### 范围与运行约束

- 所有数据保存在本地，不上传云端。分享文件位于 `<profile.dir>/trajectory-shares/`；文件权限 0600。链接使用随机 192-bit 标识，不包含宿主登录 token。生成分享即授予持有链接者所选快照的读取权。
- 当前 `127.0.0.1` 地址生成的链接仅本机可用。团队访问须由用户已有的可达宿主地址提供；本功能不会自动开放监听端口或部署公网服务。宿主停止期间链接无法访问，重启同一 profile 后恢复。
- 公开页面不提供会话控制接口；报告在无脚本、无同源权限的 sandbox iframe 中渲染，附带 CSP 与 no-store。密码尝试按链接和来源地址限制为每分钟十次。
- 最多保留 100 份分享，每份 HTML 不超过 2 MB；过期超过一天的文件会在创建后续分享时清理。清理后的链接显示不存在。可在分享菜单中撤销刚生成的链接。
- 分享报告不包含原始消息正文、工具参数或替换内容预览。JSON 是用户主动下载的原始投影，不是分享页面，可能包含投影保留的内容节选。
- “完整报告”范围是宿主当前可读的聚合数据与有界历史投影，不是原始全量事件日志。完整事件日志仍使用诊断数据区的宿主导出入口。
- PDF 使用 2× 中文画布渲染后嵌入 JPEG，适合阅读、打印和分享；不包含可选择检索的文本层。Markdown / HTML 用于可编辑、可检索的文本报告。

### 验证

- 真实历史会话投影读取、两会话比较、指标高亮及归一化页面检查。
- 浏览器下载 PDF，Poppler 检查 A4 与页数，渲染检查中文、表格、图表及分页。
- 密码分享实际创建、独立页面解锁及撤销后无法访问。
- 自动化覆盖最低值与并列、缺失值、读取时机、模板章节、HTML 转义、PDF 字节偏移、密码散列与持久化、公开/密码/过期/撤销路由。
