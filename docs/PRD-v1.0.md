## 1. 产品概述

### 1.1 产品定位

**dsh-eval-control** 是 DeepSeek Harness (DSH) 的评测控制与轨迹分析插件，提供：
- **上下文可视化**：实时展示上下文窗口组成、演化、压缩事件
- **轨迹分析**：工具调用、错误率、重试、Token 消耗等指标
- **智能诊断**：基于数据分析的告警与优化建议
- **多智能体协作追踪**：Team 模式下的成员活动、委派深度、并发峰值

### 1.2 目标用户

- DSH 插件开发者（调试自己的插件）
- Agent 评测工程师（分析评测结果）
- 高级用户（优化 Agent 配置）

### 1.3 竞品分析

| 维度 | dsh-context (竞品) | dsh-eval-control (我们) |
|------|-------------------|------------------------|
| 核心卖点 | 上下文可视化 | 上下文可视化 + 轨迹分析 + 智能诊断 |
| 上下文组成 | ✅ 饼图/堆叠图 | ⚠️ 待实现 |
| 上下文演化 | ✅ 时间线 | ⚠️ 待实现 |
| 压缩事件 | ✅ 可视化 | ⚠️ 待实现 |
| 消息级 Token | ✅ 每条消息计数 | ⚠️ 待实现 |
| 工具调用分析 | ❌ 无 | ✅ 错误率、重试、重复调用 |
| Team 协作 | ❌ 无 | ✅ 成员活动、委派深度 |
| 证据链 | ❌ 无 | ✅ 质量标记、证据引用 |
| 智能告警 | ❌ 无 | ⚠️ 待实现 |
| 导出功能 | ❌ 无 | ⚠️ 待实现 |

### 1.4 核心策略

**让他能看到的，我们也能看到；他看不到的（为什么这样、怎么优化），我们都能看到。**

## 3. 功能详细规格

### 3.1 上下文窗口实时可视化 (P0)

#### 3.1.1 功能描述
实时显示当前上下文窗口的占用情况和组成结构。

#### 3.1.2 交互逻辑

**位置**：Dashboard 顶部，固定显示

**组件**：
1. **占用率仪表盘**
   - 环形进度条，显示 `已用 Token / 窗口上限`
   - 颜色编码：
     - `< 60%`：绿色
     - `60%-80%`：黄色
     - `> 80%`：红色（闪烁提醒）
   - 中心显示百分比数字
   - 点击展开详情面板

2. **组成堆叠条**
   - 水平堆叠条，按类型分段：
     - 系统提示（蓝色）
     - 对话历史（灰色）
     - 工具定义（橙色）
     - 文件内容（紫色）
     - 压缩摘要（青色）
   - 每段显示 Token 数和占比
   - Hover 显示该段详细内容预览

**数据源**：
- `sessionStats` 投影的 `contextWindow` 字段
- 每次 `assistant/message` 事件更新

**刷新频率**：实时（每次模型调用后）

#### 3.1.3 边界情况
- 窗口上限未知时：显示"未知上限"，仅显示已用 Token 数
- 数据不可用时：显示占位符"暂无数据"

### 3.2 上下文组成拆解 (P0)

#### 3.2.1 功能描述
详细展示上下文窗口中各部分内容的 Token 占用。

#### 3.2.2 交互逻辑

**位置**：Dashboard 中部，可展开面板

**组件**：
1. **组成饼图**
   - 饼图显示各部分占比
   - 图例显示：类型、Token 数、百分比
   - 点击扇区高亮对应内容

2. **详细列表**
   - 表格形式，列：类型、Token 数、占比、操作
   - 操作列：
     - "查看内容"：弹出模态框显示该部分原始内容
     - "复制"：复制该部分内容
   - 支持排序（按 Token 数、按类型）

3. **内容预览模态框**
   - 标题：类型名称 + Token 数
   - 内容区：原始内容（可滚动）
   - 底部：关闭按钮、复制按钮

**数据源**：
- 从 `sessionStats` 的 `contextComposition` 字段解析
- 需要 DSH 宿主提供上下文组成数据

**交互流程**：
```
用户点击饼图扇区 → 高亮列表中对应行 → 点击"查看内容" → 弹出模态框
```

#### 3.2.3 边界情况
- 组成数据不可用时：显示"宿主未提供组成数据"
- 内容过长时：截断显示，提供"展开"按钮

---

### 3.3 消息级 Token 计数 (P0)

#### 3.3.1 功能描述
每条消息显示输入/输出 Token 数，支持按消息筛选和排序。

#### 3.3.2 交互逻辑

**位置**：Dashboard 下部，消息列表区

**组件**：
1. **消息列表**
   - 每行显示：
     - 消息序号（#1, #2, ...）
     - 角色图标（用户/助手/系统）
     - 消息摘要（前 50 字符）
     - 输入 Token 数
     - 输出 Token 数
     - 累计 Token 数
     - 时间戳
   - 支持排序：按 Token 数、按时间
   - 支持筛选：按角色、按 Token 范围

2. **消息详情面板**
   - 点击消息行展开
   - 显示完整消息内容
   - 显示 Token 分布（文本、工具调用、文件等）
   - 显示关联事件（工具调用、压缩等）

3. **高亮功能**
   - "最耗 Token 的消息"：红色高亮 Top 3
   - "异常消息"：黄色高亮（Token 数突增/突降）

**数据源**：
- `assistant/message` 事件的 `usage` 字段
- `tool/call` 和 `tool/result` 事件

**交互流程**：
```
用户点击消息行 → 展开详情面板 → 显示完整内容和 Token 分布
用户点击"最耗 Token"筛选 → 列表按 Token 数降序排列，Top 3 高亮
```

#### 3.3.3 边界情况
- 消息无 usage 数据时：显示"—"
- 消息内容过长时：截断显示，提供"展开"按钮

---

### 3.4 上下文演化时间线 (P1)

#### 3.4.1 功能描述
可视化整个会话过程中上下文窗口的变化趋势。

#### 3.4.2 交互逻辑

**位置**：Dashboard 中部，图表区

**组件**：
1. **时间线图表**
   - X 轴：轮次/时间
   - Y 轴：Token 数
   - 折线图显示：
     - 上下文窗口占用（蓝色实线）
     - 窗口上限（红色虚线）
     - 压缩事件（绿色竖线标记）
     - 注入事件（橙色竖线标记）
   - 支持缩放（拖拽选择区域）
   - 支持悬停查看具体数值

2. **事件标记**
   - 压缩事件：绿色三角形，Hover 显示压缩详情
   - 注入事件：橙色圆形，Hover 显示注入来源
   - Token 激增：红色菱形，Hover 显示原因

3. **图例和筛选**
   - 图例显示各线条含义
   - 点击图例可隐藏/显示对应线条
   - 筛选器：只看压缩事件、只看注入事件等

**数据源**：
- 每个轮次的 `contextWindow` 快照
- `compaction/start`、`compaction/end`、`compaction/summary` 事件
- 注入相关事件

**交互流程**：
```
用户拖拽选择区域 → 图表放大该区域
用户 Hover 压缩事件标记 → 弹出 Tooltip 显示压缩详情
用户点击图例"压缩事件" → 隐藏所有压缩事件标记
```

#### 3.4.3 边界情况
- 数据点过多时：自动降采样，保持图表流畅
- 无压缩事件时：不显示绿色标记

---

### 3.5 压缩/注入事件可视化 (P1)

#### 3.5.1 功能描述
详细展示每次压缩和注入事件的影响。

#### 3.5.2 交互逻辑

**位置**：Dashboard 下部，事件列表区

**组件**：
1. **事件卡片列表**
   - 每个事件一个卡片，显示：
     - 事件类型图标（压缩/注入）
     - 时间戳
     - 压缩前 Token 数 → 压缩后 Token 数
     - 回收率（百分比）
     - 触发原因（自动/手动）
   - 点击卡片展开详情

2. **事件详情面板**
   - 压缩事件：
     - 压缩前上下文快照（可滚动查看）
     - 压缩后上下文快照
     - 被压缩掉的内容摘要
     - 压缩算法信息
   - 注入事件：
     - 注入来源（用户/系统/工具结果）
     - 注入内容预览
     - 注入后上下文变化

3. **对比视图**
   - 左右分栏显示压缩前后对比
   - 高亮显示被删除/修改的内容
   - 支持同步滚动

**数据源**：
- `compaction/start`、`compaction/end`、`compaction/summary` 事件
- 注入相关事件（需要从 DSH 宿主获取）

**交互流程**：
```
用户点击事件卡片 → 展开详情面板
用户点击"对比视图" → 左右分栏显示压缩前后内容
用户滚动左侧 → 右侧同步滚动
```

#### 3.5.3 边界情况
- 压缩详情不可用时：显示"详情不可用"
- 内容过长时：提供"下载完整日志"按钮

### 3.6 交互式 Dashboard 重构 (P1)

#### 3.6.1 功能描述
重新设计 Dashboard 布局，提升信息密度和可读性。

#### 3.6.2 交互逻辑

**布局结构**：
```
┌─────────────────────────────────────────────────────────┐
│ 顶部状态栏：上下文占用率 | 当前模式 | 会话时长          │
├─────────────────────────────────────────────────────────┤
│ 关键指标区（4 个卡片）：                                  │
│ [Token 消耗] [工具调用] [压缩频率] [错误率]             │
├─────────────────────────────────────────────────────────┤
│ 可视化区（可切换 Tab）：                                  │
│ [上下文演化] [Token 趋势] [工具调用分布] [Team 活动]    │
├─────────────────────────────────────────────────────────┤
│ 详细数据区（可折叠）：                                    │
│ [消息列表] [事件列表] [指标明细]                        │
└─────────────────────────────────────────────────────────┘
```

**组件**：
1. **顶部状态栏**
   - 固定显示，不随滚动消失
   - 显示关键状态：上下文占用率、当前模式、会话时长
   - 点击可展开快速操作菜单

2. **关键指标卡片**
   - 4 个卡片横向排列
   - 每个卡片显示：指标名称、当前值、趋势箭头（↑↓）
   - 点击卡片跳转到对应详细视图

3. **可视化区 Tab**
   - Tab 切换不同图表
   - 每个图表支持：
     - 缩放、拖拽
     - 悬停查看详情
     - 图例筛选
     - 导出为图片

4. **详细数据区**
   - 可折叠，默认展开
   - 支持搜索、筛选、排序
   - 支持批量操作（复制、导出）

**交互流程**：
```
用户点击指标卡片 → 滚动到对应详细视图并高亮
用户切换 Tab → 图表平滑过渡动画
用户折叠详细数据区 → 仅显示标题栏，点击展开
```

#### 3.6.3 边界情况
- 屏幕较小时：自动调整为单列布局
- 数据加载时：显示骨架屏

### 3.7 智能告警与建议 (P2)

#### 3.7.1 功能描述
基于数据分析，主动提供告警和优化建议。

#### 3.7.2 交互逻辑

**位置**：Dashboard 右侧，告警面板

**组件**：
1. **告警列表**
   - 每个告警一个条目，显示：
     - 严重级别图标（🔴 严重 / 🟡 警告 /  建议）
     - 告警标题
     - 告警详情
     - 时间戳
     - 操作按钮（"查看"、"忽略"、"标记已处理"）
   - 按严重级别排序
   - 支持筛选：只看未处理、按级别筛选

2. **告警详情面板**
   - 点击告警条目展开
   - 显示：
     - 告警原因分析
     - 相关数据图表
     - 优化建议（可操作）
     - "应用建议"按钮（自动调整配置）

3. **告警规则配置**
   - 设置页面，可配置：
     - 上下文占用率阈值（默认 80%）
     - 压缩频率阈值（默认 5 次/千 Token）
     - 错误率阈值（默认 10%）
     - 是否启用某类告警

**告警规则**：
| 告警类型 | 触发条件 | 建议 |
|---------|---------|------|
| 上下文满载 | 占用率 > 80% | 启用更激进的压缩策略 |
| 频繁压缩 | 压缩频率 > 5 次/千 Token | 减少工具定义数量 |
| 高错误率 | 工具错误率 > 10% | 检查工具参数格式 |
| Token 浪费 | 重复调用 > 3 次 | 启用结果缓存 |
| 长间隔 | 步骤间隔 > 30s | 检查工具响应时间 |

**数据源**：
- 实时指标数据
- 历史趋势数据

**交互流程**：
```
系统检测到告警 → 告警面板出现红点提示
用户点击告警 → 展开详情，显示原因和建议
用户点击"应用建议" → 自动调整配置并应用
用户点击"忽略" → 告警标记为已忽略，不再显示
```

#### 3.7.3 边界情况
- 无告警时：显示"一切正常"绿色提示
- 告警过多时：按严重级别折叠，只显示最严重的

### 3.8 对比分析 (P2)

#### 3.8.1 功能描述
支持多次运行或不同配置的对比分析。

#### 3.8.2 交互逻辑

**位置**：独立"对比"页面

**组件**：
1. **会话选择器**
   - 下拉列表选择要对比的会话
   - 支持多选（2-4 个会话）
   - 显示每个会话的摘要信息

2. **对比图表**
   - 并排显示多个会话的指标
   - 图表类型：
     - 柱状图：Token 消耗对比
     - 折线图：上下文演化对比
     - 雷达图：多维度能力对比
   - 支持高亮差异最大的指标

3. **差异报告**
   - 自动生成差异摘要
   - 显示：
     - 哪个会话 Token 消耗最少
     - 哪个会话压缩频率最低
     - 哪个会话错误率最低
   - 提供"最佳实践"建议

**数据源**：
- 本地存储的会话数据
- 需要从 DSH 宿主获取历史会话数据

**交互流程**：
```
用户选择 2-4 个会话 → 点击"开始对比"
系统生成对比图表和差异报告
用户点击某个指标 → 高亮显示该指标在各会话中的差异
用户点击"最佳实践" → 显示优化建议
```

#### 3.8.3 边界情况
- 会话数据不可用时：显示"数据不可用"
- 会话差异过大时：归一化显示

### 3.9 导出与分享 (P2)

#### 3.9.1 功能描述
支持导出分析报告和分享可视化结果。

#### 3.9.2 交互逻辑

**位置**：Dashboard 顶部工具栏

**组件**：
1. **导出菜单**
   - 点击"导出"按钮弹出菜单
   - 选项：
     - 导出为 PDF（完整报告）
     - 导出为 Markdown（文本报告）
     - 导出为 JSON（原始数据）
     - 导出图表为 PNG

2. **分享功能**
   - 点击"分享"按钮
   - 生成分享链接（只读视图）
   - 支持设置有效期（7 天/30 天/永久）
   - 支持设置访问权限（公开/密码保护）

3. **报告模板**
   - 提供预定义报告模板：
     - 简洁版（关键指标 + 图表）
     - 详细版（完整数据 + 分析）
     - 团队版（多会话对比 + 建议）
   - 支持自定义模板

**数据源**：
- 当前会话的所有数据

**交互流程**：
```
用户点击"导出" → 选择格式和模板
系统生成报告并提供下载
用户点击"分享" → 生成链接并复制到剪贴板
用户发送链接给团队成员 → 团队成员打开只读视图
```

#### 3.9.3 边界情况
- 导出失败时：显示错误提示和重试按钮
- 分享链接过期时：显示"链接已过期"提示

## 4. UI/UX 设计规范

### 4.1 设计原则
- **信息密度高**：在有限空间内展示更多信息
- **层次清晰**：重要信息突出，次要信息可折叠
- **交互流畅**：减少点击次数，提供快捷操作
- **视觉统一**：与 DSH 原生界面风格一致

### 4.2 颜色规范
- 主色：`#1a73e8`（蓝色，用于主要操作）
- 成功：`#34a853`（绿色，用于正常状态）
- 警告：`#fbbc04`（黄色，用于警告状态）
- 错误：`#ea4335`（红色，用于错误状态）
- 背景：`#ffffff`（白色）/ `#202124`（深色模式）
- 文字：`#202124`（深色）/ `#e8eaed`（浅色模式）

### 4.3 字体规范
- 标题：`16px`，`font-weight: 600`
- 正文：`14px`，`font-weight: 400`
- 辅助文字：`12px`，`opacity: 0.7`
- 代码：`monospace`，`12px`

### 4.4 响应式设计
- 桌面端（> 1200px）：多列布局
- 平板端（768px - 1200px）：两列布局
- 移动端（< 768px）：单列布局，关键指标优先

## 5. 技术实现考虑

### 5.1 数据源
- **DSH 宿主 API**：`sessionStats`、`pluginInventory/list`、`pluginManager/listBundles`
- **本地计算**：基于事件流的指标聚合
- **缓存策略**：最近 N 个事件缓存，避免重复计算

### 5.2 性能优化
- **虚拟滚动**：长列表使用虚拟滚动
- **懒加载**：图表数据按需加载
- **Web Worker**：复杂计算放到 Worker 线程
- **防抖/节流**：高频事件处理

### 5.3 兼容性
- **浏览器**：Chrome 90+、Firefox 88+、Safari 14+
- **DSH 版本**：`>=0.1.7-alpha.1`
- **Node 版本**：`^22.19.0 || >=24.0.0`

### 5.4 隐私与安全
- **数据本地化**：所有数据存储在本地，不上传云端
- **敏感信息过滤**：工具参数、消息正文不展示
- **访问控制**：只读模式，不修改 DSH 配置
